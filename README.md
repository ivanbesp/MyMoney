# 🌱 Финансовый трекер

## Возможности

- ✅ Доходы и расходы с категориями и подкатегориями
- ✅ Управление категориями (добавить, изменить, удалить)
- ✅ Статистика за день / неделю / месяц / год / всё время
- ✅ Диаграммы: динамика и расходы по категориям
- ✅ Копилки с прогресс-баром и дедлайнами
- ✅ **Финансовый пульс** - индикатор здоровья бюджета
- ✅ **Инсайты** - умные советы на основе ваших данных
- ✅ Мультивалютность: RUB / USD / EUR с ручными курсами
- ✅ Резервная копия JSON и экспорт в CSV
- ✅ Все данные хранятся в localStorage (приватно, офлайн)

## Как устроены даты и валюты

Две вещи, которые легко сломать обратно, поэтому они вынесены явно.

**Даты - календарные, строкой `YYYY-MM-DD`, в локальном времени.** Нигде не
используется `toISOString()`: он отдаёт UTC, и запись уезжает на соседний день -
в UTC+ ломался график, в UTC− пропадал фильтр «Сегодня». Все преобразования
живут в `lib/dates.ts`, сравнение периодов - лексикографическое по строкам.

**Курс фиксируется в момент создания операции** (поле `rate` - сколько рублей
стоила единица валюты). Правка курсов в настройках влияет только на новые
записи; суммы уже внесённых операций не пересчитываются задним числом.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck  # проверка типов
npm test           # тесты логики: миграции, даты, курсы, бэкап
npm run test:tz    # те же тесты в четырёх часовых поясах
```
